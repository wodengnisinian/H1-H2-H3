# 为什么要改变权重集中方式

R08 新开发原问的训练角色损失与候选损失对照都 100% 选对了两个关系词中的首步关系，两者的最终首跳准确率也同为 70.78%。其排序差的点估计为 0 个百分点，配对双侧 95% 区间约为 −0.17 至 +0.17 个百分点。额外的首步标签没有显示出胜过相同特征下候选监督的作用。

新候选的改写准确率为 84.06%，四问全对率为 38.17%。原问较直接首位仅高 4.61 个百分点，尚未触发独立验收。R04 给正确关系的词位分配全部权重时，原问达到 85.83%。两个结果指向一个可以干预的变量：词权重是否充分集中于已经识别出的首步关系。

R12 冻结 R08 的三个向量、训练样本和 H2，逐题取预测质量最大的关系，在该关系的全部词位上等分概率。该干预不读正确标签。主对照沿用完全相同的权重与特征，按 R08 的软概率赋权。记录硬化带来的净纠正、改错、门内外结果及不同句式的表现。训练标签损失的 R08 假设和 R12 推理干预的假设分别判定。

R07、R08 均在开发阶段止步。正式验收仍限一次。R12 仅在达到同一事前开发门槛后才有资格冻结，没有根据接近门槛的幅度调整通过规则。
