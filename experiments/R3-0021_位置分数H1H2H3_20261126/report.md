# R21 逐轮报告：论文机制 + Token 位置分数的完整 H1/H2/H3

2026 年 11 月 26 日。在方法论文的共享词权重机制上给每个题面词位增加可学习位置分数 s_j（t_j = w·h_j + s_j），主变体 pos_table；诊断变体 pos_linear（s_j = a·j + b）与 pos_only（w 冻结为 0）。训练数据与预算和论文一致：12,000 图、8,000 门控样本、Adam lr=0.003、batch 128、12 轮。预注册见 [configs/protocol.json](configs/protocol.json)，运行环境为论文原环境（Windows 本机）。

词面顺序基线在四个面板为 49.89% / 49.89% / 51.67% / 51.67%。H1 的 80% 门槛只在改写面板被 pos_linear 和 pos_only 达到；所有变体的原问面板都远低于 80%，主变体 pos_table 四个面板均未达标（报告见 [results/h1/h1.json](results/h1/h1.json)）。

双基线 H3 验收要求相对两个基线各自 ≥5 个百分点且下界 >0，本轮 pos_table 对池化基线差 0.61 个百分点，**验收未通过**。开封已记录一次，本轮不复测。pos_table（75.06%）与原公式 learned（75.17%）基本持平，说明绝对位置分数在新图上没有带来相对池化的额外增益。

## 结论

1. Token 位置分数在论文开发集上对 H1 的贡献集中在改写面板（pos_linear/pos_only 超过 80%），对原问面板无效；H2 排名上 pos_table 仅有 0.3–0.9 个百分点的小幅提升。
2. 全新独立 H3：pos_table 相对直接首位 +9.26pp（达标），相对池化 +4.39pp（差 0.61pp 未达标），双基线验收未通过，一次性开封已用。
3. 位置分数方向目前没有证据支持进入正式验收；若继续，建议改为相对位置特征（距时序线索词的距离分档，即 R08 的 φⱼ 思路），而非绝对词位表。
