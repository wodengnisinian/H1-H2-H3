# R22 逐轮报告：关系词软读出（无显式顺序特征）

2026 年 11 月 27 日。把论文原公式的逐词 softmax 限制在两个关系提及位置（t_j = w·h_j 只在关系词处参与归一化），完全去掉显式顺序特征（无 φⱼ、无位置分数），训练预算与论文一致（8,000 门控样本、Adam lr=0.003、batch 128、12 轮）。主变体 relmask_cand 用候选损失（与论文相同），诊断变体 relmask_role 用首步关系角色损失。评测在 R16/R17 冻结的 600 图队列上，判据与 R16 相同。预注册见 [configs/protocol.json](configs/protocol.json)。运行于新租服务器（torch 2.10.0 环境），云端日志见 [logs/stage1.log](logs/stage1.log)。

## 主结果（图内平均三种子与问法，三题型等权，配对 Bootstrap 10,000 次）

| 变体 | H1 识别率 | 相对词面顺序增益 / 单侧 95% 下界 | H2 首跳准确率 | 相对均匀权重增益 / 单侧 95% 下界 | H1 | H2 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| learned（论文原公式） | 70.16% | +20.16 / +18.09 | 72.20% | +3.04 / +2.44 | 未过 | 过 |
| **relmask_cand（主变体）** | **78.61%** | **+28.61 / +26.16** | **75.37%** | **+6.20 / +5.47** | **未过** | **过** |
| relmask_role（诊断） | 79.02% | +29.02 / +26.55 | 76.19% | +7.03 / +6.31 | 未过 | 过 |

词面顺序基线 50.00%，均匀权重 H2 为 69.17%。把软读出限制到关系词后，H1 比原公式高 8.45 个百分点，H2 高 3.17 个百分点，且相对两个正式基线的增益都显著（对直接首位 +9.87pp，对池化 +4.59pp）。但 H1 绝对门槛 80% 仍差 1.39 个百分点（relmask_role 差 0.98 个百分点）。

## 分视图 H1 / H2

| 变体 | 原问 | 改写 | 未见句式 |
| --- | ---: | ---: | ---: |
| learned | 59.83% / 64.61% | 77.22% / 73.83% | 43.44% / 50.50% |
| relmask_cand | 69.06% / 65.67% | **89.39% / 83.28%** | 34.89% / 45.89% |
| relmask_role | 68.00% / 66.50% | 88.94% / 84.22% | 36.50% / 44.50% |

关系词掩码在改写句式上把 H1 拉到约 89%，原问也提升约 10 个百分点；代价是未见句式 H1 从 43.44% 掉到 34.89%——去掉非关系词的上下文后，未见过句式里可用的信息变少。行为指标（主变体）：同图四问全对 9.33%（原公式 3.00%，R12 79.33%），改写选同一事实稳定 75.44%，候选覆盖率 100%。

## 训练与实现

- 三个种子 relmask_cand 末轮 NLL 0.00178 / 0.00240 / 0.00147，relmask_role 末轮 0.00174 / 0.00432 / 0.00187。
- 冻结依赖：model.py SHA-256 `f85636ff…`、历史 w 检查点与队列哈希 `cf7d3ba2…` 逐项核对一致。
- 代码：[code/r22_relmask.py](code/r22_relmask.py)；统计复用 R18 的 [r18_stats.py](code/r18_stats.py)（主变体可配置）。

## 结论

1. 只读关系词、不显式用顺序，是继 R18/R21 位置分数之后最有效的一步：H1 +8.45pp、H2 +3.17pp，H2 达标，H1 距 80% 门槛最近到 0.98pp。
2. 组合方向：relmask 与角色损失几乎等价；若要过 80%，下一步可以在关系词上做受控对照，例如把两个关系词的 h 拼起来做 64 维双关系读出，或只加一维「最近时序线索的符号」这类最小顺序线索。
3. 未见句式的 H1 下降提示纯关系词掩码牺牲了泛化；正式验收前需要同时看未见句式表现。
