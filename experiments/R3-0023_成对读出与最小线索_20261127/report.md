# R23 逐轮报告：双关系成对读出与最小顺序线索

2026 年 11 月 27 日。在 R22 关系词软读出（H1 78.61%）基础上试两个方向：A. 双关系成对读出 relpair——反称形式 w·(h_A − h_B) 直接判断两个关系词谁是首步；B. 最小顺序线索 cue——关系词掩码上加一维最近时序标记符号（先类 +1、后类 −1，遇标点重置）的标量权重。训练预算与论文一致，评测在 R16/R17 冻结 600 图队列。预注册见 [configs/protocol.json](configs/protocol.json)，运行于新租服务器（torch 2.10.0）。

## 主结果（图内平均三种子与问法，三题型等权，配对 Bootstrap 10,000 次）

| 变体 | H1 识别率 | 相对词面顺序增益 / 下界 | H2 首跳准确率 | 相对均匀权重增益 / 下界 | H1 | H2 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| learned（论文原公式） | 70.16% | +20.16 / +18.09 | 72.20% | +3.04 / +2.44 | 未过 | 过 |
| relmask_cand（R22） | 78.61% | +28.61 / +26.16 | 75.37% | +6.20 / +5.47 | 未过 | 过 |
| relpair（成对读出） | 78.61% | +28.61 / +26.16 | 75.37% | +6.20 / +5.47 | 未过 | 过 |
| relpair_role（诊断） | 79.02% | +29.02 / +26.55 | 76.19% | +7.03 / +6.31 | 未过 | 过 |
| **cue（最小顺序线索）** | **82.59%** | **+32.59 / +30.16** | **76.88%** | **+7.71 / +7.00** | **过** | **过** |

**cue 是论文原公式一脉中第一个同时通过 H1 与 H2 门槛的变体**：H1 82.59%（≥80%），H2 76.88%，相对直接首位 +11.38pp（下界 +9.01）、相对池化 +6.10pp（下界 +5.09）、相对均匀权重 +7.71pp（下界 +7.00）。注意：relpair 与 relmask_cand 逐位相同——两个单次出现关系词上的 softmax 与 logistic(差值) 在数学上等价，因此「成对读出」在该数据上不引入新信息；真正起作用的是最小顺序线索。

## 分视图与行为指标

| 变体 | 原问 H1/H2 | 改写 H1/H2 | 未见句式 H1/H2 |
| --- | ---: | ---: | ---: |
| relmask_cand | 69.06 / 65.67 | 89.39 / 83.28 | 34.89 / 45.89 |
| cue | 74.83 / 67.33 | 91.72 / 84.94 | 39.17 / 47.22 |

cue 行为指标：同图四问全对 24.17%（原公式 3.00%、relmask 9.33%、R12 79.33%）；改写选同一事实稳定 64.61%；语义反转后两问都对 62.08%。未见句式 H1 仍只有 39.17%，是最明显的短板。

## 训练与实现

- cue 为 64 维 w + 1 个标量 s，候选损失；三种子末轮 NLL 0.00177 / 0.00236 / 0.00146。
- relpair_role 首轮误把候选序号当作事实编号（H1 48.94%），修正为事实编号后重跑为 79.02%，与 R22 relmask_role 一致，交叉验证了实现。
- 冻结依赖：model.py `f85636ff…`、历史 w 检查点、队列哈希 `cf7d3ba2…` 核对一致。代码 [code/r23_pair_cue.py](code/r23_pair_cue.py)，统计复用 [r18_stats.py](code/r18_stats.py)。

## 结论与下一步

1. 最小顺序线索（每词位一个符号标量）叠加关系词掩码即可把 H1 推过 80%（82.59%），H2 同步达标；这比 R18/R21 的绝对位置表和成对读出都有效。
2. 按 R16/R17 补充协议，cue 已满足开发入选条件，下一步是冻结该模型与代码，抽一组全新独立图做一次性 H3 正式验收（对直接首位与池化双基线各 +5pp 且下界 >0）。
3. 风险提示：cue 的未见句式 H1 仅 39.17%、四问全对 24.17%，独立验收若包含新句式可能受挫；H3 是否开封与队列设计需要授权后冻结。
