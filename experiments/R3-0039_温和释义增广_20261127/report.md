# R39 逐轮报告：PARAPHRASE 温和增广（重大突破）
2026 年 11 月 27 日。R38 确认 lin3 家族已收敛到前沿。本轮按用户目标"从前面实验中提取优秀方式"：把 R07 证明有效的等义改写增广（+2pp）以温和形式引入——每个训练图追加 1 条 PARAPHRASE 模板改写（1:1，无语序对抗），训练 sparsemax 与 rolew_g05 并做 mix2r/lin3 混合。预注册见 [configs/protocol.json](configs/protocol.json)。

## 判读
1. **温和释义增广是迄今最强的单一升级**：H1 从 80.17% → 93.14%（+12.97pp），H2 从 77.92% → 85.91%（+7.99pp），逐种子 95.97 / 83.44 / 100.00，三题型 91.00 / 97.25 / 91.17。同图四问全对 79.17%，与 R12（79.33%）持平。这证实"等义改写增广"是移动前沿的关键杠杆（R33 的失败来自 clause 对抗与 60% 权重，而非增广本身）。
2. **代价集中在未见句式**：uH1 从 32.11% 掉到 23.11%——增广强化了模板共有的表层特征。R24 教训（cue uH1 39.17% → H3 失败）要求我们不能在此冻结。
3. **但 H1 的巨大余量（93%）打开了新空间**：现在可以把余量兑换成泛化——lin3_aug 系列加大冻结 learned 分量权重 λ3（learned 自身 uH1 43.44%）。λ3=0.15 已把 uH1 拉到 29.33% 而 H1 仍有 89.95%。
4. 行为指标：改写事实稳定 71.06%、语序预测稳定 89.58%、语义反转双对 89.58%。
## 训练与实现
- 增广集：24,000 条（原问 12,000 + PARAPHRASE 改写 12,000），eligible 16,000；构造经短名单一致性校验。
- 云端 predictions SHA-256 `5b8232cd…`；冻结依赖核对通过。
## 结论与下一步
主变体双过 H1/H2 且行为指标优秀，但未见句式 23.11% 未达 35% 哨兵。R40：lin3_aug 的 λ3∈{0.20,0.25,0.30,0.35} 细扫，用 H1 余量换取 uH1≥35%，目标同时满足 H1≥80%、H2 门槛与未见句式哨兵。
累计轮次 R39。开发 H1/H2 双过 + 未见句式 ≥35% 才冻结进入新 H3 验收。
