# 原始记录与补充实验的复核入口

在 Windows 指定归档根目录使用 Python 3.11 或 3.12 执行以下只读命令。三条一致性检查覆盖原研究和两个补充轮次。Windows 端校验只依赖 Python 标准库，不运行模型。

```powershell
python -B "logs/恢复校验/verify_r3_local_archive.py" . --verify
python -B "experiments/R3-0014_Order_20261124-1903/code/verify_r14.py" "experiments/R3-0014_Order_20261124-1903"
python -B "experiments/R3-0015_Tie_20261124-1910/code/verify_r15.py" "experiments/R3-0015_Tie_20261124-1910"
```

原研究的 Linux 复跑环境、检查点和封条见 [原研究复跑说明](../../reports/复跑与中断恢复.md)。`r3-closed-20261124.zip` 保留当时原始根目录，`remote_files.json` 保留恢复时的云端文件指纹。当前根目录的登记、状态和科研日志还包括其后的 R14、R15；还原原始云端快照时应使用新的空目录。

R14 和 R15 的 `configs/command.json` 记录实验实际使用的 Linux 命令，`logs/exit.json` 记录运行结果。在复现副本中，恢复 R3 目录及同级的 `inputs`（从 `datasets/归档输入.zip` 解压）。使用每轮自己的 `code/` 里同名实验脚本，将 `--r3` 与 `--inputs` 指向恢复目录，把 `--out` 指向新的空目录。R15 的 `--r14` 指向 R14 的 `results`。两个实验使用同一 Python 3.12.13、PyTorch 2.10.0+cu128 和 NumPy 1.26.4 环境，在 CPU 上运行。逐文件数据与模型清单在各自 `data/frozen-inputs.json`，云端精确命令和退出状态在各自 `configs/` 与 `logs/`。已有 R09 的原始预测可用于统计复核，原研究的正式抽样机会已经使用。
