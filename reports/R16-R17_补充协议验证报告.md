# 共享词权重原公式与 R12 改进版本的验证结果

2026 年 11 月 24 日在已分配云实例完成 R16 和 R17。按补充协议冻结的开发判据，论文原始共享软权重通过 H2，H1 距绝对门槛仍差 9.84 个百分点。采用时序线索读头和硬关系选择的 R12 在同一开发队列同时通过 H1、H2。该 R12 另有同一组冻结权重在既有正式 H3 上通过双基线验收的记录。新开发判据的冻结时间晚于那次正式验收。本次新增两轮均为开发实验。

## 同一批图上的主结果

| 版本 | H1 识别率 | 相对词面顺序的增益／单侧 95% 下界 | H2 首跳准确率 | 相对均匀词权重的增益／单侧 95% 下界 |
| --- | ---: | ---: | ---: | ---: |
| R16 论文原式 | 70.16% | +20.16 / +18.09 个百分点 | 72.20% | +3.04 / +2.44 个百分点 |
| R17 冻结 R12 | 100.00% | +50.00 / +48.00 个百分点 | 91.44% | +22.28 / +21.32 个百分点 |

词面顺序基线为 50.00%，全有效词位均匀加权的 H2 为 69.17%。H1 要求达到 80% 且相对词面基线的下界大于零；H2 要求相对均匀权重的增益至少为 2 个百分点且下界大于零。两版本在相同图上的 H2 准确率相差 19.24 个百分点，双侧配对 95% 区间为 +18.13 至 +20.35。此跨版本差异包含读头和硬选择的共同变化。[冻结协议](../configs/共享权重续研冻结协议_20261124.json) · [逐图跨版本复算](../analysis/R16-R17_配对比较与验收版本校验.json)

| 指标 | R16 论文原式 | R17 冻结 R12 |
| --- | ---: | ---: |
| 同图四问全对 | 3.00% | 79.33% |
| 关系反转前后两问都对 | 50.25% | 89.67% |
| 同义改写后仍选同一事实 | 60.67% | 84.33% |
| 未见句式的 H1 / H2 | 43.44% / 50.50% | 100.00% / 79.44% |
| 主评测候选覆盖率 | 100.00% | 100.00% |

R12 在未见句式上仍能选对首步关系，实际首跳证据命中率降至 79.44%。即使首步关系正确，模型仍可能被方向分、门控或证据匹配分引向错误候选。现有比较不能把全部余错归因于其中某一项。在自然开门的逐题判断中，R16 相对均匀权重纠正 398 次、改错 132 次；R12 纠正 1,532 次、改错 0 次。这些是按问法和种子计数的描述性结果，表格的统计区间以图为单位计算。

## 数据、对照和范围

新队列包括 600 张具有唯一人员集合的合成图，每种题型 200 张。每图评测原问、改写和另外一个未见句式；200 张可逆图再评测四问，共 2,600 个问法。未见句式为单列挑战。主结果先在图内平均预定问法及种子 1701、2701、3701，再按题型等权汇总，分题型按图配对重抽 10,000 次。两个版本使用完全相同的输入文件，SHA-256 为 `cf7d3ba220b789d978a56667409a3b6b5deb4832b8556d81d96f615acd05c1ad`。

论文原式的每个 64 维向量与原始训练归档逐值一致。训练时冻结其余参数，每个种子用 8,000 个门控开启且金标入围的样本训练 12 轮。R16 包含均匀、随机、打乱、词面顺序、匹配预算的单组／四组、随机标签探针、纯方向分、旧第一层、池化与首位等 16 组预测。R17 共 19 组，另含同权重的软读出及关系词位支持集消融。R12 的软读出 H2 为 78.19%，硬选择后为 91.44%。三个种子与全部原始对照都已保留。[R16 报告、逐种子指标和代码](../experiments/R3-0016_原公式_20261124/report.md) · [R17 报告、逐种子指标和代码](../experiments/R3-0017_硬关系选择_20261124/report.md)

## 已使用的正式验收

原 R09 在 R12 达到当时的开发入选条件后冻结模型、代码和统计规则，随后抽取 4,800 张新图。累计 14,400 次原问判断中，R12 答对 12,906 次，准确率为 89.625%。相对池化模型提高 18.77 个百分点，单侧 95% 下界 +18.17；相对直接首位提高 23.69 个百分点，下界 +22.60。两项均满足点估计至少 +5、下界大于零的正式判据。本次核对了 R17 的三个主检查点、关系读头、硬选择评分代码、基础模型代码及历史冻结清单，摘要均与 R09 的冻结记录吻合。[历史正式判定](../analysis/H3验收判定.json) · [验收版本对应关系](../analysis/R16-R17_配对比较与验收版本校验.json)

因此，原公式的 H1/H2 联合目标尚未达标。对 R12，证据由本轮前瞻性开发达标和先前预注册的 H3 通过两部分组成；补充协议发布后没有新的独立验收。此前 R11 的状态词反例以及真正需要读取后继边的 R10 单独挑战也应分开解读。当前累计实验 17/20 轮，正式开封 1/1 次。达到开发判断终点并用尽正式检验额度后封存。两次进程各使用现有实例一条 CPU 线程，耗时约 34.75 秒和 28.92 秒，未新增付费资源。

## 复现与交付

每轮的 `data/cohort/` 保存实际输入和分割清单，`checkpoints/` 保存三个主检查点，`code/` 保存实验脚本和源码差异，`configs/` 保存环境、冻结配置、运行命令及共享依赖 SHA-256，`results/` 保存逐题预测、逐图指标、置信区间和错例，`logs/` 保存云端快照、过程日志、用量及退出码。历史计算代码和大型输入由归档中的原始快照及 `datasets/归档输入.zip` 提供。

在本地从归档根目录运行以下只读命令可重算两轮主指标，并核验文件哈希和登记事件。需要 Python 与 NumPy。

```powershell
python -B "experiments/R3-0016_原公式_20261124/code/r3_shared_verify.py" "experiments/R3-0016_原公式_20261124"
python -B "experiments/R3-0017_硬关系选择_20261124/code/r3_shared_verify.py" "experiments/R3-0017_硬关系选择_20261124"
```

要在新 Linux 目录复现推理，将云端历史 R3 还原为 `R3/`，在同级解压 `datasets/归档输入.zip` 得到 `inputs/`。按每轮 `configs/launch.json` 的顺序在空输出目录运行队列生成、逐种子推理和统计。R17 复用 R16 的同一队列；`--version` 分别取 `original` 与 `r12`。实际解释器和展开后的命令见 `logs/stages.jsonl`。逐轮版本和对照可从[全部实验登记](../experiment_registry.jsonl)、[所有轮次指标总表](../experiment_summary.csv)和[前 15 轮总结](本次云端实验与归档总结.md)追溯。
